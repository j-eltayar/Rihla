# Rihla# Rihla



This repository contains two Expo React Native applications:Test test me.

## Directory Structure

- **`rihla-mobile/`** - Original Rihla mobile app
  - Location-based list management app
  - Features: Lists, locations with ratings, map view, search, filters
  
- **`rihla-mobile-v2/`** - New Rihla mobile app (in development)
  - Second version of the Rihla application

## Getting Started

### Running the Original App (rihla-mobile)

```bash
cd rihla-mobile
npm install
npx expo start
```

### Creating/Running the New App (rihla-mobile-v2)

```bash
cd rihla-mobile-v2
# Initialize your new Expo app here
npx create-expo-app@latest .
npm install
npx expo start
```

## Development

Each app is independently managed with its own:
- `package.json`
- `node_modules`
- Build configurations
- Dependencies

Navigate to the specific app directory before running any npm or expo commands.
